# because Blackwell (sm_120) engines are architecture-locked (spec §7.4).
#
# `interval=1` = run SGIE every other frame. 25 FPS per stream × 8–12
# cams × 128-D OSNet_x0_25 still fits comfortably on RTX 5070 Ti;
# dropping to interval=2 is the first dial if we see GPU pressure
# (spec §16.5 OOM playbook).
